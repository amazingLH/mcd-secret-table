项目名称：麦麦密桌 SecretTable
项目地址：https://github.com/amazingLH/mcd-secret-table
项目简介：多人点餐时，不必在群里公开个人预算和偏好。麦麦密桌由千问协调 Agent 提出餐单，各参与者的浏览器本地评估器检查私人条件，仅发送匿名接受/拒绝、满意度和少量自愿接受的餐品组合；模型依据反馈迭代，程序按全员接受与最低满意度排序，最后通过麦当劳官方 MCP 整单核价并在浏览器重新检查预算。真实验证门店、在售菜单、餐品详情、营养与核价六类工具，已跑通两轮真实模型协商，保留 responseId 和官方 traceId；提供无需 Token 的在线固定数据演示、20 项测试、可运行源码及 Skill。当前同一浏览器模拟三人，不宣称多设备或密码学隐私隔离，不执行下单或支付。在线演示：https://amazinglh.github.io/mcd-secret-table/
